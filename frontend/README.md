# Frontend Overview
Navigate to the **./src/app** directory to view the frontend of the application.  
The root of all is the **index.tsx** file.

## Assets and Images

Navigate to the **./assets/images** folder.  
The images in the **/app** folder are the icons used inside the project itself.

## Utilities

The **./utils** folder contains helper files that provide functionality only (types, functions, etc.).

## How to Run

1. If you don't already have Node.js installed, [install Node.js](https://nodejs.org/en/download).

2. Inside the **frontend** folder run
    ```bash
    npm install
    ```
    to install all the required packages.

3. Run
    ```bash
    npm install
    ```
    to start the application.
